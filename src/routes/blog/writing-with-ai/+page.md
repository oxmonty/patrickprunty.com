Nolan famously prefers the use of analog mediums: the flip phone, typewriter, etc. But as we trundle towards an age of full digital assimilation, at what point… does using a laptop for writing become analog?

1. Always write the first draft yourself 
2. Set some rules for your writing 

If you’re writing regularly, you’ll have these rules, maybe not written down but they’re there in your mind somewhere. If you don’t have rules, and you just write what you want, whatever way you write it, that’s because you’re still trying to find your _voice_. I’ll keep my rules under lock-and-key but as an example: “Use of a reference or analogy from pop culture (ie celebrity, movie, TV series, etc.) which you have 80% confidence will be agreed by with the target audience of your piece” is a rule with an associated score. If my piece has this, it bumps the score. Another more general rule: “Assert personal opinion with confidence: don’t use ‘I believe…’, use assertive tone…” … Cut, cut, cut on final draft

And here’s a rewrite informed by Orwell’s six rules from “Politics and the English Language”:

“Say what you mean. Cut every hedge — ‘I believe,’ ‘I feel,’ ‘it seems’ — that lets you hide behind vagueness. If you hold an opinion, state it plain. If you can’t defend it without a qualifier, rethink the opinion, not the phrasing. Use short words, active voice, and no more of either than the point requires.”

> I think that the mandate for using AI is supposed to be interpreted as "give these tools a fair chance to be useful, being open to adjusting the ways you work if necessary so that the tools can help you work better and faster" if you find a class of problems for which the approach above doesn't end up giving you better and/or faster results, then don't use the tools (but keep an open mind anyway in case you do find a way to make the tools work for that class of problems too in the future)
